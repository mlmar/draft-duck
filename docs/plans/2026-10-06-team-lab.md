# Team lab roadmap

## Goals

Give managers a saved roster, a category strength chart, and a workspace to compare additions and removals. One comparison flow supports both trades and hypothetical add/drop decisions.

## Shared requirements

- U1: Add a Team tab where users manually select their players.
- U2: Display team strengths in a bar chart.
- U3: Show the effect of adding or removing players through the chart and an optional short summary.
- Process: Execute one leaf at a time with internal self-review; the user reviews one complete final PR.
- Readability: all logical blocks of code must be commented for human readability.

## Accepted behavior, v2

- Example: A manager searches a candidate into the aligned slot beside a saved player and swaps the row. The chart compares the full saved roster against the proposed left lineup, including unchanged teammates.
- Bulk example: If row one is manually swapped, then Preview all candidates swaps eligible candidate rows only. Turning bulk preview off restores those rows while preserving the manual choice.
- Layout: Desktop shows aligned Team lineup and Candidates columns with row swap controls. Mobile toggles between lists while keeping row order, counterpart identity, row dimensions, and text placement fixed; each swap control sits to the right of its active player slot.
- Ownership: Each row stores saved-player and candidate identities independently from displayed sides. Actual roster edits pause while previewing; candidate selection remains available.
- Apply/reset: Reset restores initial sides and retains candidates. Apply lineup saves the displayed left lineup and clears candidates and swap state.
- Selection: Roster size and positions are unlimited. Search uses the existing CSV player catalog; duplicate IDs are prevented across the workspace.
- Chart: Default to average unweighted per-player category z-scores; offer a total contribution toggle. Overlay the proposed lineup as a lighter filled signed bar directly on the saved-team solid bar on one shared track per category. Show both exact values, deltas, and player counts. Raw shooting percentages combine makes and attempts.
- Persistence: Store actual team membership separately on this device. Candidate and preview state is temporary; the draft profile remains untouched.
- Data boundaries: Use the existing historical CSV and ranker. No Yahoo/NBA integration, schedules, live availability, projections, accounts, new chart package, or API changes.
- Visual direction: Inherit the light Analysis Desk, Public Sans, cool neutral surfaces, graphite text, cobalt actions, restrained borders, corners, and responsive controls.
- Decision record: The user accepted this specification and authorized implementation by saying “implement” on 2026-10-19, then specified the branch prefix `feat/`. The user will review the final PR; there are no human result-review pauses between implementation leaves.
